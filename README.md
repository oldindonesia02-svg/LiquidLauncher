# 🚀 Liquid Glass Launcher

A beautiful iOS 16-inspired liquid glass launcher for Android with glassmorphism design, smooth animations, and app management.

## 📋 Features

- ✨ Glassmorphism UI design (iOS 16 style)
- 📱 Grid-based app launcher
- 🎨 Beautiful blur and transparency effects
- 🔄 Smooth animations
- 🎯 App launch functionality
- 📦 Installed apps management

## 🛠️ Tech Stack

- **Language**: Kotlin
- **UI Framework**: Jetpack Compose
- **Build System**: Gradle
- **Target**: Android 8.0+ (API 26)

## 🎯 Quick Start

1. Clone or download this repository
2. Open in Android Studio
3. Sync Gradle
4. Run on emulator/device
5. Enjoy your liquid glass launcher!
